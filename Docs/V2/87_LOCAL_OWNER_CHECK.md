# 87 · 로컬 직접 확인 안내

2026-10-17 완성 묶음(0–6단계)을 소유자가 이 PC에서 직접 확인하는 방법이다. 원격 D1·R2·배포는 건드리지 않는다.

## 준비 상태

- 로컬 D1(`apps/web/.wrangler/state`)에 migration 0000–0033이 적용돼 있다([86번](./86_CHATGPT_PLAN_MAIN_ANALYZER.md)의 절차).
- 노션 5개 DB(영상 로그·컨텐츠 로그·게임 로그·지식 창고·묵상)를 관리자 계정에 가져왔다. 기록 795건이고 운동 로그 등은 제외했다.
- ChatGPT 플랜 연결이 로컬 D1에 설치돼 있다. 새 기록의 AI 정리는 이 연결로 처리한다.

다시 가져와야 할 때만 아래를 실행한다. 반복 실행해도 중복되지 않고, 사용자가 고친 값은 덮어쓰지 않는다. **앱을 끈 상태에서** 실행한다(같은 로컬 DB를 동시에 쓰지 않도록).

```bash
npm run import:notion
```

가져온 기록의 날짜 정리와 입력 안내 초안만 다시 만들 때는 `npm run import:notion -- --finish-only`를 쓴다.

## 실행

```bash
npm run dev:local
```

1. 브라우저에서 `http://localhost:3000/v2/library`를 연다.
2. 관리자 계정(`apps/web/.env.local`의 관리자 이메일·비밀번호)으로 로그인한다.
3. 끌 때는 터미널에서 Ctrl+C를 누른다.

`dev:local`은 원격 자격 증명을 빈 값으로 덮어 원격 DB에 닿지 않는다. 20초마다 로컬 처리 대기열을 돌려 새 기록을 분석한다.

## 확인 목록

| # | 화면 | 확인할 것 |
| --- | --- | --- |
| 1 | 보관함 | 795건이 노션 날짜 순서로 보이는가. 상태는 "받은 기록", 날짜는 각 기록의 날짜인가. '노션·가져옴·마이그레이션' 표시가 없는가. |
| 2 | 기록 화면 | 유형 배지(영상 로그 등)가 DB대로 하나씩 붙었는가. 필드 값이 "원문에서 명시함"으로 보이는가. 공개 범위가 "일반", 원본이 "글 원본"으로 보이는가. |
| 3 | 기록 화면 · 이어진 것 | "이 기록과 이어진 것"이 분류·사람·단체·플랫폼별 개수와 최근 5건으로 묶여 보이는가. "N개 모두 보기"가 그 묶음을 펼치는가. |
| 4 | 대상 화면 | 감독·제작사·플랫폼 이름을 누르면 그 대상과 이어진 기록이 분류별로 보이는가. 펼친 목록(최대 100건)의 "검색에서 모두 보기"가 결과를 보여 주는가. |
| 5 | 검색 | 분류 필터와 "연결된 기록 검색"(대상 조건)이 결과를 돌려주는가. |
| 6 | 입력 템플릿 | "자동 초안"에 DB별 안내 5개가 있는가. "이번에 사용"을 누르면 새 기록 화면에 "장르를 남길까요?"처럼 내 항목 이름의 질문이 나오는가. 고르기 전에는 새 기록 메뉴에 나오지 않는가. |
| 7 | 새 기록 → AI 정리 | 게임·영상 같은 기록을 새로 쓰면 기존 분류와 필드(예: 게임의 "진행 상태")를 다시 쓰는가. 새 이름을 만들지 않는가. |
| 8 | 확인할 내용 | 판단이 필요한 항목만 목록에 오르는가. 기록 화면에서 나머지는 "필요할 때만 확인하세요 · AI 정리 제안 N개"로 접혀 있는가. |
| 9 | 처리 상태 | 정리 제안만 남은 기록이 '확인 필요'로 표시되지 않는가. |
| 10 | 휴대폰 폭 | 브라우저 개발자 도구에서 폭 375px로 보면 가로 스크롤이 없는가. |

## 알려진 점

- 날짜만 있는 노션 기록은 기록 화면 머리에 "오후 9:00:00" 같은 시각이 함께 보인다. 날짜가 하루 밀리지 않도록 그날 정오(UTC)로 저장했기 때문이다.
- 노션 원본의 값은 그대로 들어왔다. 원본에 잘못 적힌 감독·제작사도 그대로다.
- 제목 없는 노션 행은 "제목 없음"으로 보인다. 날짜 없는 행은 가져온 날짜로 보인다.
- 가져온 기록은 AI 정리를 끈 채 들어왔다. 처리 상태에는 AI를 끄고 저장한 기록과 같이 "분석하지 않음"으로 보인다. AI 정리는 새로 쓰는 기록에서 확인한다. 이미 저장한 기록에 나중에 AI 정리를 요청하는 화면은 아직 없다.
